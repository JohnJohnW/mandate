# References

Why read this: every short-cite in square brackets across the docs, code comments and the deck resolves here. If a cite is not in this file, it is a mistake and should be removed or added.

Citation style: `[SHORT-CITE]` in text, optionally with a control or section after a space, for example `[NIST-SP800-53 AC-6]`. The "Checked" column records when we last opened the URL ourselves. "Brief" means the source was checked while the project brief was prepared on 17 Oct 2026. "Not re-checked" means we have not yet opened it in this repository's history and the cite should be treated with care.
